# منصة اشرحلي التعليمية

واجهة عربية RTL متجاوبة لموقع اشرحلي، منشورة عبر GitHub Pages.

## الإصدار الأول
- صفحة تعريفية رئيسية.
- عرض البرامج التدريبية.
- بحث وتصفية حسب المجال.
- منهجية التعلم ومميزات المنصة.
- أسئلة شائعة تفاعلية.
- دعم شاشات الهاتف والكمبيوتر.

## حالة المنتج
هذه نسخة واجهة أمامية للمعاينة وليست نظاماً تعليمياً تشغيلياً بعد. لا يوجد حالياً تسجيل حسابات حقيقي أو قاعدة بيانات أو لوحة إدارة متصلة أو تشغيل دروس أو دفع إلكتروني. ستنفذ هذه الخدمات لاحقاً مع اختبارات الأمان.

## النشر
يستخدم المستودع GitHub Actions لنشر ملفات الموقع. يجب تفعيل Pages من إعدادات المستودع واختيار GitHub Actions كمصدر للنشر.
